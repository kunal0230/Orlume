# Orlume — GPU Parameter Dictionary

> **Every parameter** in `GPUProcessor.params`. Authoritative reference for defaults, types, ranges, and batching behavior.

---

## ⚠️ CRITICAL WARNING — Curve LUT Params

**`curveLutRgb`, `curveLutRed`, `curveLutGreen`, `curveLutBlue` must be `null` when unused.**

Setting them to `0` corrupts the shader — it interprets `0` as a valid LUT of 256 zeros, mapping every pixel to black. See System Contract **LAW 2**.

---

## Standard Adjustment Params

These are numeric params with default `0`. They feed into the standard develop pipeline via `WebGL2Backend.renderDevelop()`.

| Param | Type | Default | Range | Description |
|-------|------|---------|-------|-------------|
| `exposure` | `float` | `0` | -5.0 to +5.0 | Exposure compensation (EV stops) |
| `contrast` | `float` | `0` | -100 to +100 | Tonal contrast |
| `highlights` | `float` | `0` | -100 to +100 | Highlight recovery/boost |
| `shadows` | `float` | `0` | -100 to +100 | Shadow lift/crush |
| `whites` | `float` | `0` | -100 to +100 | White point adjustment |
| `blacks` | `float` | `0` | -100 to +100 | Black point adjustment |
| `temperature` | `float` | `0` | -100 to +100 | White balance: warm (+) / cool (-) |
| `tint` | `float` | `0` | -100 to +100 | White balance: green (-) / magenta (+) |
| `vibrance` | `float` | `0` | -100 to +100 | Selective saturation boost |
| `saturation` | `float` | `0` | -100 to +100 | Global saturation |
| `clarity` | `float` | `0` | -100 to +100 | Midtone contrast / local contrast |
| `structure` | `float` | `0` | -100 to +100 | Fine detail enhancement |
| `dehaze` | `float` | `0` | -100 to +100 | Haze removal |

> ⚠️ The param name is `structure`, NOT `texture`. This was a bug in `PresetsModule`.

**Safe to batch:** Yes. You can write directly to `gpu.params[name] = value` for multiple standard params and call `gpu.render()` once at the end.

## HSL Per-Channel Params (24 total)

Pattern: `hsl{Channel}{Color}` where Channel ∈ {Hue, Sat, Lum} and Color ∈ {Red, Orange, Yellow, Green, Aqua, Blue, Purple, Magenta}.

All default to `0`, range -100 to +100.

| Hue Shifts | Saturation | Luminance |
|-----------|-----------|-----------|
| `hslHueRed` | `hslSatRed` | `hslLumRed` |
| `hslHueOrange` | `hslSatOrange` | `hslLumOrange` |
| `hslHueYellow` | `hslSatYellow` | `hslLumYellow` |
| `hslHueGreen` | `hslSatGreen` | `hslLumGreen` |
| `hslHueAqua` | `hslSatAqua` | `hslLumAqua` |
| `hslHueBlue` | `hslSatBlue` | `hslLumBlue` |
| `hslHuePurple` | `hslSatPurple` | `hslLumPurple` |
| `hslHueMagenta` | `hslSatMagenta` | `hslLumMagenta` |

> Hue shifts: -100 to +100 maps to -180° to +180° in the shader.

**Safe to batch:** Yes.

## Color Grading Params (11 total)

These control the 3-way color grading wheels (shadows/midtones/highlights).

| Param | Type | Default | Range | Description |
|-------|------|---------|-------|-------------|
| `shadowsHue` | `float` | `0` | 0–1 (maps to 0°–360°) | Shadow tint hue |
| `shadowsSat` | `float` | `0` | 0–1 (maps to 0–100%) | Shadow tint saturation |
| `shadowsLum` | `float` | `0` | -100 to +100 | Shadow luminance shift |
| `midtonesHue` | `float` | `0` | 0–1 | Midtone tint hue |
| `midtonesSat` | `float` | `0` | 0–1 | Midtone tint saturation |
| `midtonesLum` | `float` | `0` | -100 to +100 | Midtone luminance shift |
| `highlightsHue` | `float` | `0` | 0–1 | Highlight tint hue |
| `highlightsSat` | `float` | `0` | 0–1 | Highlight tint saturation |
| `highlightsLum` | `float` | `0` | -100 to +100 | Highlight luminance shift |
| `colorBalance` | `float` | `0` | -100 to +100 | Global shadows↔highlights balance |
| `colorBlending` | `float` | **`50`** | 0 to 100 | Zone overlap amount |

> ⚠️ `colorBlending` defaults to `50`, not `0`. This is the only non-zero default in the entire param set.

**Safe to batch:** Yes. `ColorGradingModule.updateGrade()` demonstrates the batching pattern:
```javascript
gpu.params[`${zone}Hue`] = h;
gpu.params[`${zone}Sat`] = s;
gpu.params[`${zone}Lum`] = l;
gpu.render(); // single render
```

## Curve LUT Params (4 total)

These store 256-entry lookup tables generated by the ToneCurveEditor. They feed into a separate curves pass in the shader, NOT the standard adjustment pipeline.

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `curveLutRgb` | `Float32Array(256) \| null` | **`null`** | RGB master curve LUT |
| `curveLutRed` | `Float32Array(256) \| null` | **`null`** | Red channel curve LUT |
| `curveLutGreen` | `Float32Array(256) \| null` | **`null`** | Green channel curve LUT |
| `curveLutBlue` | `Float32Array(256) \| null` | **`null`** | Blue channel curve LUT |

**Safe to batch:** Yes — write to `gpu.params` directly, then call `gpu.render()`.

**Reset pattern:**
```javascript
if (key.startsWith('curveLut')) {
    this.params[key] = null;    // ✅ CORRECT — identity curve
} else {
    this.params[key] = 0;       // standard numeric reset
}
```

## Param Sets by Module

This maps which module owns/manages which params:

| Module | Params |
|--------|--------|
| Global sliders (EditorUI) | `exposure`, `contrast`, `highlights`, `shadows`, `whites`, `blacks`, `structure`, `clarity`, `dehaze`, `temperature`, `tint`, `vibrance`, `saturation` |
| HSLModule | All `hsl*` params (24) |
| ColorGradingModule | `shadowsHue/Sat/Lum`, `midtonesHue/Sat/Lum`, `highlightsHue/Sat/Lum`, `colorBalance`, `colorBlending` |
| ToneCurveModule | `curveLutRgb`, `curveLutRed`, `curveLutGreen`, `curveLutBlue` |
| PresetsModule | Writes to any/all standard + HSL params. Does NOT write curve LUTs. |

## GPUProcessor.reset() Behavior

`GPUProcessor.reset()` sets:
- All standard/HSL/color grading params → `0` (except `colorBlending` which goes to `0`, **not** its default `50` — [VERIFY: check if reset restores colorBlending to 50 or 0])
- All curve LUT params → `null`
- Then calls `render()`.

---

## EditorState.resetAdjustments() Behavior

`EditorState.resetAdjustments()` sets all keys in `globalAdjustments` to `0`. This includes color grading params but does NOT reset `colorBlending` to `50` — it sets it to `0`.

> [VERIFY: Confirm whether `EditorState.resetAdjustments()` should handle `colorBlending`'s non-zero default specially. Currently it sets all to `0` via a simple loop.]

## Slider ID Conventions

| Slider Type | Input ID | Value Display ID |
|------------|----------|-----------------|
| Global adjustment | `slider-{param}` | `val-{param}` |
| Mask adjustment | `slider-mask-{param}` | `val-mask-{param}` |
| Brush setting | `slider-brush-{setting}` | `val-brush-{setting}` |
| God Rays | `slider-godrays-{param}` | `val-godrays-{param}` |
| Export quality | `slider-export-quality` | `val-export-quality` |

> ⚠️ **Never** use bare `param` as an element ID. Always use the prefixed form. See System Contract **LAW 5**.
