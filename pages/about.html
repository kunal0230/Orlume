Hey! I'm an engineering student passionate about computer graphics, WebGPU shaders, and computer vision.

I built Orlume out of curiosity to see if modern browser APIs could replace heavy, subscription-gated desktop editors. Everything runs 100% client-side on your own GPU with zero server uploads, zero accounts, and zero paywalls.

It has been an awesome learning playground for graphics programming, shader pipeline math, and on-device neural model inference.

Open Editor GitHub

Why I Built This

Most photo editing software is locked behind monthly subscriptions or cloud upload requirements. I wanted an open, private studio that opens instantly in any browser without asking for a credit card, email, or cloud sync.

0 Subscriptions 100% Free Forever No Sign-up

Zero Cloud Uploads

Your photos never leave your device because Orlume has no backend server. Every shader pass, tone curve LUT, and neural model executes directly in your browser's local memory using your device's own GPU.

No Backend Server Local GPU Memory Zero Tracking

What's Under The Hood

Built with native web standards and zero heavy desktop wrappers. Hardware-accelerated image manipulation powered by WebGPU, WebGL2, and client-side machine learning.

WebGPU (WGSL) WebGL2 (GLSL) ONNX Runtime Web Transformers.js Web Workers Three.js

Open for Exploration

As a student project, the entire repository is public on GitHub under the MIT license. Whether you want to study the shader pipelines, report glitches, or contribute, it's open for everyone.
