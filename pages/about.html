A browser-native photo studio exploring WebGPU & neural vision.

Hey, I'm Kunal. Orlume is a personal hobby project I built to experiment with real-time WebGPU shaders, on-device AI models, and browser graphics pipelines — completely free, client-side, and without servers.

I'm an engineering student with a deep fascination for computer graphics, WebGPU compute pipelines, and computer vision.

I started Orlume out of curiosity to answer a simple question: Why should photo editing require monthly subscription paywalls or uploading personal photos to remote cloud servers?

Modern web standards like WebGPU, WebGL2, and WebAssembly SIMD have made browsers capable of desktop-grade real-time rendering. Orlume has been my hands-on playground to write shaders from scratch, implement 3D point-light relighting, and execute machine learning models locally on the user's GPU.

Guiding Philosophy

Why I Started This Project

The core motivations that shaped how Orlume was designed and built.

01 / PRIVACY

Personal Photos Belong on Your Device

Modern cloud photo apps often send your raw photos across the internet to be processed on remote clusters. Orlume proves that client devices have ample GPU power to execute neural depth estimation and color grading locally without sending a single byte over the wire.

02 / EDUCATION

A Student's Graphics Playground

Building Orlume has been an incredible computer science deep dive into writing custom WGSL and GLSL fragment shaders, calculating normal vectors from depth maps, implementing 3D lighting equations, and managing WebAssembly memory.

03 / ACCESSIBILITY

Creative Software for Everyone

High-quality photo editing tools shouldn't be gated behind costly monthly subscriptions. By removing server infrastructure costs, Orlume remains freely accessible to students, hobbyists, and creators worldwide.

Architecture

What's Under The Hood

Built entirely on open web standards with zero heavy native desktop wrappers.

Compute & Shaders

WebGPU & WGSL

Next-generation web graphics API enabling high-throughput compute pipelines, tone curves, and real-time color grading.

Universal Fallback

WebGL2 & GLSL

Robust hardware-accelerated fallback shaders ensuring smooth 60 FPS performance across legacy and mobile browsers.

Neural Depth

Depth Anything V2

State-of-the-art monocular depth estimation running directly inside the browser using ONNX Runtime Web and WebAssembly.

3D Relighting

Three.js & Normal Maps

Real-time virtual point lights, ambient bounce, and interactive specular highlights cast onto 2D photographs.

Multi-Threading

Web Workers & SIMD

Offloading image decoding, mask calculations, and heavy arrays to background threads to prevent UI frame drops.

Zero Server Footprint

Client-Only Architecture

Static client-side deployment with zero databases, user sessions, or photo storage. 100% private by design.

Questions & Answers

Frequently Asked Questions

Common questions about Orlume, the licensing, and how to get involved.

Is Orlume really completely free?

Yes, 100% free forever. There are no paid tiers, no watermarked exports, and no subscriptions. Because it runs on your device, there are no server compute costs to pass on to you.

Do my photos ever get uploaded anywhere?

Never. Every image loaded into Orlume stays entirely inside your browser's local memory. No image data is ever uploaded, cached, or transmitted to any server.

Can I see the source code or contribute?

Yes! The entire project is open-source under the MIT license on GitHub. Contributions, bug reports, and shader improvements are always welcome.

Can I use this for professional projects?

Absolutely. Orlume exports high-resolution images up to full 4K and 8K with zero watermarks. You retain full ownership and copyright of any image you edit.

Ready to try in-browser photo editing?

No downloads, no sign-ups, and no paywalls. Open the editor in any browser tab and start editing with 60 FPS WebGPU shaders.
